## If a take fails mid-record

1. Stop recording (Ctrl+F10)
2. Note the take number as failed — don't delete the file (sometimes partial is usable)
3. Rehearse the problem moment once
4. Re-record
5. Move on — don't chase perfection on any single take, you have multiple
